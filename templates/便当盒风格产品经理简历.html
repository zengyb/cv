PROJECT 01 / AI智能 Agent+RAG重构

智谱 AI 生产力智能协同助手

项目背景： 解决 B 端用户在知识沉淀和信息清洗上的流程摩擦。原有大模型在长文本处理时极易发生上下文溢出及语义偏离（Tokens context limit），响应延迟高达 4.2s。

技术攻坚： 重构 RAG 向量检索路径，建立多路召回重打分排序模型（Rerank），保留高语义精度的同时将 Token 总运算能耗压缩 25%。搭建 Multi-Agent 多智能体协同引擎，拆解复杂问答到专门的微型 Agent 并发执行。

活跃 MAU 120万+
付费转化率 12.4%
首字响应 (TTFT) < 1.2 秒
PROJECT 02 / 商业中台 智能竞价托管

美团 · 本地商家广告智能投放中台

业务痛点： 抖音/美团商家端长尾商户（SMB）缺乏专业的广告投放分析人员，原本复杂庞杂的竞价后台让商户无从下手，无法衡量投放 ROI，导致续存留存低。

产品攻坚： 引入自动化出价智能托管引擎（Auto-bidding），建立长效 LTV 竞价预测系统。配合基于广告大盘自适应匹配的动态创意拼装算法（DCO），帮助商家实现无门槛、高转化的一键自动化稳健投放。

整体点击 (CTR) +18.2%
商户续费留存 +15.0%
商家整体 ROI 提升 20%
PROJECT 03 / 增长策略 PLG 体验度量再造

抖音套件新客 PLG 留存攻坚战役

业务瓶颈： 在多渠道高成本引流后，新激活用户在进入 onboarding 注册流程时的摩擦损耗和流失率高达 65%。未能在第一时间将用户带入产品感知阈值（Aha Moment，魔法时刻）。

产品攻坚： 重塑新客进入旅程，削减多重无用信息验证。建立自适应用户画像标签，在新客进入页面 3 秒内直接完成其首份智能文档及 AI 对话伴侣摘要的功能呈递，极大降解链路摩擦。

新客注册转化 +22%
新客 D7 留存 +8.0%
魔法时刻触达 缩短 65%
PROJECT 04 / 架构演进 高并发OT引擎

企业级多人高并发文档协作矩阵

核心痛点： 在处理百人级企业跨部门同时在线编辑文档时，高并发读写极易发生锁冲突和版本覆盖，实时数据在复杂网络下的同步高延迟造成严重的协同摩擦。

产品攻坚： 主导引入 OT（Operational Transformation）算法引擎与 WebSocket 专线双向实时长连接。重构分布式网关，支持百万级冲突合并与毫秒级版本追平，并在工程侧深度优化渲染管线，极大地改善了响应体验。
